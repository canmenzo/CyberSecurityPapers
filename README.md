# 🛡️ Cyber Security Papers

[![license](https://img.shields.io/github/license/canmenzo/CyberSecurityPapers)](LICENSE)
![format](https://img.shields.io/badge/format-PDF-EC1C24?logo=adobeacrobatreader&logoColor=white)

Team papers, lab reports and slides by Mehmet Can Ozmen and classmates from the Information Security (LIS4774, LIS4777) and Organizational Information Security (LIS5775) courses at Florida State University, 2021 to 2023.

### 📚 Contents
- 🌐 [WebVulnerabilities.pdf](WebVulnerabilities.pdf): *Vexing Vulnerabilities in Web Applications*, LIS4774 term paper (Team A). Penetration tests against a team web server using PHP injection and XSS, and why both come down to missing input validation and sanitization.
- 📊 [WebVulnerabilitiesPresentation.pdf](WebVulnerabilitiesPresentation.pdf): slides for the same study (environment, network topology, analysis, lessons learned).
- 🧱 [PaloAltoFirewall2.pdf](PaloAltoFirewall2.pdf): LIS4774 Lab 8, configuring a Palo Alto PAN-OS 9.1.9 firewall step by step with screenshots.
- 🦠 [MalwareAttackDetectionPrevention.pdf](MalwareAttackDetectionPrevention.pdf): *Malware: Attack, Detection, and Prevention*, LIS4777 midterm paper (Team B). Blue-team hardening of Apache web servers behind Palo Alto, pfSense and Security Onion, then red-team attacks with Kali and Metasploit.
- 🔥 [Palo Alto Firewall Configuration.pdf](Palo%20Alto%20Firewall%20Configuration.pdf): LIS4777 Team B screenshots of the Palo Alto (NAT rules with hit counts) and pfSense setup used in that exercise.
- ✈️ [AirAsiaDataBreachAnalysis.pdf](AirAsiaDataBreachAnalysis.pdf): LIS5775 slides on the 2022 Daixin ransomware attack on AirAsia: the attack, its cost, CISA detection guidance and countermeasures.
